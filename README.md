# משחק היצירה - מצגות

אתר המצגות הציבורי של סדנת משחק היצירה.

- [אתר המצגות](https://aharonyaircohen.github.io/game-of-creation-presentations/)
- [מצגת מפגש 1](https://aharonyaircohen.github.io/game-of-creation-presentations/meeting-01/)

## מבנה

- `index.html` - תפריט שבעת שיעורי הסדנה, עם מסך כניסה. מפגש 1 פעיל; מפגשים 2-7 מסומנים כ״בפיתוח״ ואינם קישורים.
- `meeting-01/index.html` - המצגת הראשונה, קובץ עצמאי עם חתימה, גופנים ואיורים מוטמעים; פועל גם ללא אינטרנט.
- `.nojekyll` - הגשה ישירה של קבצים סטטיים.

גם דף התפריט וגם מצגת מפגש 1 דורשים את אותה סיסמה קבועה. בכל פתיחה ורענון נדרשת כניסה מחדש; קישור ישיר למצגת אינו עוקף את מסך הכניסה שלה. זהו מסך כניסה בצד הדפדפן בלבד, לא מנגנון אבטחה: הקוד והתוכן נמצאים ב-HTML הציבורי.

## פרסום ועדכונים

GitHub Pages מגיש את שורש ענף `main`. המאגר מכיל תוצרי פרסום שנבחרו בלבד. המקור הקנוני, הטיוטות וכלי ההפקה נשארים במאגר המקור הפרטי ואינם מסונכרנים אוטומטית לכאן.

לעדכון מצגת: מפיקים ובודקים אותה במאגר המקור, מעתיקים במכוון רק את ה-HTML המאושר למסלול המפגש, שומרים ב-GitHub ובודקים את האתר החי. אין לערוך את טקסט השיעור בעותק הפרסום. בעדכון התפריט בלבד משאירים את קובצי המצגות ללא שינוי.

כל הזכויות בתוכן ובנכסי המותג שמורות לבעליהם. פרסום המאגר אינו רישיון לשימוש חוזר.
