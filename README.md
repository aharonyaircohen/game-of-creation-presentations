# משחק היצירה - מצגות

אתר הסדנה הציבורי של משחק היצירה.

- [אתר הסדנה](https://aharonyaircohen.github.io/game-of-creation-presentations/)
- [קישור מפגש 1 הישן](https://aharonyaircohen.github.io/game-of-creation-presentations/meeting-01/) - מפנה לאותו אתר, עם שמירת קישור לשקף.

## מבנה

- `index.html` - מסמך אחד עם כניסה, תפריט שבעת השיעורים ומצגת מפגש 1. בחירת המפגש וכפתור ״תפריט״ מחליפים תצוגה בתוך אותו מסמך, ללא iframe, מסמך נוסף או לשונית חדשה. מפגשים 2-7 מסומנים ״בפיתוח״ ואינם קישורים.
- `meeting-01/index.html` - הפניה קטנה בלבד לשורש האתר. שומרת query ו-`#slide-N`; בלי hash פותחת את `#slide-1`. אינה מכילה תוכן מצגת או מסך כניסה נוסף.
- `.nojekyll` - הגשה ישירה של קבצים סטטיים.

כניסה אחת חלה על כל האתר. לאחר כניסה מוצג התפריט או השקף שנבחר בקישור ישיר; אין בקשה נוספת בחזרה לתפריט. הכניסה נשמרת לאורך אותה לשונית וברענון. ללא כניסה קודמת התפריט והשקפים נשארים מוסתרים ובלתי ניתנים למיקוד. זהו מסך נוחות בצד הדפדפן בלבד, לא אבטחה: הקוד והתוכן נמצאים ב-HTML הציבורי.

כל 76 השקפים, סדרם, נוסחם, האיורים ועיצובם נשמרים. כתובות השקפים הן `#slide-N`; חזרה לתפריט משתמשת ב-`#menu`. ה-HTML כולל גופנים, חתימה ואיורים מוטמעים ופועל גם מקומית ללא אינטרנט.

## פרסום ועדכונים

GitHub Pages מגיש את שורש ענף `main`. המאגר מכיל תוצרי פרסום שנבחרו בלבד. המקור הקנוני, הטיוטות וכלי ההפקה נשארים במאגר המקור הפרטי ואינם מסונכרנים אוטומטית לכאן.

מפיקים את האתר באמצעות `media/presentations/build_site.py` במאגר המקור, מתוך README הסדנה, מסמך השיעור והמיפוי. בודקים את המסלול המלא כניסה → תפריט → שיעור → תפריט באותו מסמך, קישורים ישירים וישנים, רענון, מובייל ותוכן כל השקפים. מעתיקים במכוון רק את ה-HTML הנבחר ל-`index.html` ואת ההפניה למסלול הישן. אין לערוך את טקסט השיעור בעותק הפרסום. שינוי בתפריט מחייב הפקה חוזרת, לא עריכת מקור השיעור.

אחרי שמירה ב-GitHub ממתינים לפריסה וקוראים חזרה את הקבצים ואת האתר החי לפני דיווח הצלחה.

כל הזכויות בתוכן ובנכסי המותג שמורות לבעליהם. פרסום המאגר אינו רישיון לשימוש חוזר.
